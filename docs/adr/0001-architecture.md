# ADR-0001: Модульный монолит + адаптеры + фоновые задачи

## Решение

Для v1 используем модульный монолит:

- единый backend-контур;
- отдельные доменные модули;
- адаптеры внешних интеграций;
- очередь/worker для тяжелых и асинхронных операций;
- PostgreSQL как основная БД;
- Redis как кэш/очередь;
- S3-compatible storage для файлов.

## Почему

Проект большой по предметной области, но выполняется ограниченной командой/одним специалистом. Микросервисы на старте увеличат стоимость поддержки, инфраструктуры и отладки.

## Последствия

- проще поднять local/dev/stage;
- проще тестировать бизнес-потоки;
- интеграции не размазываются по коду, а живут в adapter layer;
- при росте нагрузки отдельные модули можно выделять позднее.
