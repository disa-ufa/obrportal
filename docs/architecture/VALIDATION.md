## Ограничение ручной проверки

При попытке открыть файл через интерфейс draw.io пользователь остановил управление приложением клавишей Escape. После этого действия в интерфейсе не выполнялись. Поэтому интерактивный щелчок по ссылкам, перетаскивание блока и сохранение изменений через GUI **не проверены вручную**. Структурная проверка ссылок, редактируемости объектов и отрисовка всех страниц выполнены отдельно без управления интерфейсом.

Для завершения ручной приёмки: открыть `.drawio`, перейти с «00 Обзор» к «05 Минтруд» и обратно, переместить любой блок и убедиться, что стрелка следует за ним; отменить пробное перемещение. Открыть одну ссылку ↗ и сверить имя исходного файла.

## Как повторить

```text
python docs/architecture/validate_drawio.py
python scripts/check_text_encoding.py
python scripts/check_source_bom.py
python scripts/secret_scan.py
git diff --check
```

Для визуальной проверки используйте штатный экспорт draw.io. В установленной версии нумерация аргумента `--page-index` начинается с 1 (страницы 1–9); в версиях до 27.0.2 она начиналась с 0. Пример:

```text
draw.io --export --format png --page-index 1 --output overview.png docs/architecture/obrportal-architecture.drawio
```

Проверки backend/frontend и интеграционные тесты локально не запускались: изменение документальное. Статус обязательного GitHub CI следует смотреть непосредственно в PR. Production, БД и внешние порталы в рамках проверки не использовались.
